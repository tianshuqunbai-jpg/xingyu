# 星语核心审查问题修复记录

范围：`src/lib/memory.js`、`turn.js`、`deepseek.js`，以及 `storage.js` 的任务取消接点。使用合成存储与假 API 响应验证；未读取真实聊天或调用真实 API。

## 审查发现对应修复

1. **彻底清除后其他人格任务复活**：新增 `cancelAllMemoryTasks()`，覆盖已登记的全部人格、排队与在途提炼，以及重建和关键词补全；`clearAllData()` 与 `restoreBackup()` 在写入前调用。原 `cancelPendingExtraction()` 无参仍只取消当前人格。测试覆盖 A 当前作用域、B 在途、A 排队，以及恢复备份后的 B 晚到结果。
2. **重建与补全缺少清空世代保护**：两条任务在开始时固定人格与世代；重建在请求前和响应后检查世代，清空后的结果不入库。补全在每批请求后重读当前分区，按仍存在且未手动编辑、文本未变的事实 ID 合并，保留等待期间新增事实，并在保存前再次检查世代。测试分别覆盖重建清空、补全清空、补全期间新增。
3. **旧加密全局记忆迁移成空分区**：迁移经 `readSecure` 获取明文，验证记忆结构、规范化后写新分区，回读一致才写迁移标记。锁定、损坏、写入或回读失败时保留旧记录，不留下阻碍重试的目标分区；已有目标分区不会被旧快照覆盖。测试覆盖锁定后解锁、加密信封原样保留、无效结构不标记。
4. **本地问候进入 API 历史**：历史筛选同时排除 `local: true`；合成问候回归确认不进入请求。
5. **旧出处缺少会话 ID 时误指**：没有 `messageId` 和 `sessionId` 的事实，只有出处原话确实出现在对应用户消息中才允许按旧 `turn` 回引；否则跳过。测试覆盖另一会话同一下标误指及原话匹配。
6. **私密助手原文被含蓄摘要掩盖**：排队时同时检查用户与助手原文；提炼写入时再对整批原文和摘要判断。事实和摘要共用私密标记。测试覆盖普通提问、私密回复、含蓄的事实和摘要。
7. **多行 SSE 事件误报格式错误**：按空行分隔事件，合并同一事件的多条 `data:` 后解析；兼容分块到达的 CRLF、注释和 `[DONE]`。测试覆盖跨块 JSON 与跨块 CRLF 边界。
