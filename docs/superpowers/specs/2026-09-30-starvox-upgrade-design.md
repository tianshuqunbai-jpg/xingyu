# 星语全面升级设计

用户选择：都要，按阶段全面升级（2026-09-30）。在现有 React 18 + Vite + Capacitor 工程上实施，保留人格、情绪、长期记忆与星空品牌。

## 方案取舍

1. 只修补现有两套界面：改动小，但两端仍会分叉。
2. 共用完整聊天界面与逻辑，以响应式布局适配电脑和手机（采用）：桌面现有功能完整复用，避免维护两套数据流程。
3. 重写为后端账号平台：需要服务、迁移和部署，超出本地应用升级需要。

## 第一阶段：数据与请求可靠性

- 本轮输入只提交一次；占位、失败和仅本地消息不进入 API 历史。
- 情绪只计算一次，网络故障不改变关系；停止、超时、退出、切换后不接受旧回调。
- 记忆任务绑定人格、会话、世代及稳定消息 ID；清空后旧任务不能写回；队列串行排空。
- 历史、事实、摘要和出处采用一致的私密过滤。模式仍由用户手动控制。
- 加密启停和恢复采用可回滚写入，锁定时拒绝敏感写入。备份解析无副作用。
- 存储失败明确反馈，禁止静默删除历史。旧存档兼容迁移，迁移写入成功前保留原始记录。

## 第二阶段：完整日常使用

- 所有尺寸使用同一 ChatPage，手机以抽屉承载原侧栏，支持全部记忆、备份、加密、人格和设置功能。
- 多会话：新建、切换、改名、删除、按标题与内容搜索；会话独立保存聊天和情绪。长期记忆继续按人格共享，界面明确说明。
- 消息复制、收藏、编辑后重新发送、回复重新生成、失败重试、文本导出。编辑与重生成在新会话分支执行，保留原对话。
- 保留输入草稿；滚动到历史时不被新字强拉回底部，提供返回最新按钮。
- 设置测试支持取消，成功结果只对应当前配置。错误可读、操作可重试。

## 第三阶段：感官交互和界面

- 语音：浏览器支持时可语音输入、朗读回复和停止朗读，选择语音与语速；明确识别可能调用浏览器语音服务。
- 图片：选择/预览/移除图片，压缩与大小限制，将图片以多模态内容发送给支持图像的配置；不支持时显示具体错误，不宣称全部模型支持。
- 角色继续使用现有情绪驱动头像，增加可选自定义角色图片和说话状态。真实 Live2D 需要用户提供模型及对应运行库授权，不用占位宣称已经完成。
- 优化视觉层级、设置密度、键盘焦点、触屏尺寸、窄屏布局与减少动画选项；保留已有个性化数据。

## 实施边界

- 不读取或修改用户正在使用的浏览器数据；不发布网站；不调用真实付费模型进行测试。
- 不增加后端、账号、云同步或远程图片/字体依赖。
- 新功能优先复用现有依赖；浏览器媒体能力不足时给明确说明。
- Android 先同步最新 Web 资源；仅在本机已有工具链可用时验证 APK 构建，构建限制如实记录。

## 验收

核心逻辑用合成数据和模拟网络回归：请求去重、停止/超时、跨人格队列、清空后不复活、敏感过滤、配额失败回滚、加密锁、旧备份恢复、多会话切换。浏览器验证桌面与手机布局、配置、聊天操作、搜索与恢复。生产构建通过；不以静态检查代替真实接口/设备验证。
